# 金幣酷跑 Run for Coins

3D 火車軌道跑酷遊戲，使用 [Three.js](https://threejs.org/) 製作。純靜態網頁，不需要建置步驟。

## 玩法

- 沿著三條軌道一直往前跑，吃金幣、閃避障礙
- **紅白柵欄**：跳過去
- **黃黑高架柵欄**：滑鏟從下面鑽過
- **停靠的列車**：換軌道閃開，或從**黃黑斜坡**跑上車頂
- **亮著頭燈的列車**會迎面開過來，要提早換道
- 換道時撞到側面會被彈回，3 秒內再撞一次就出局
- 速度會隨距離越來越快；分數 = 距離 + 金幣 × 10

## 道具

跑道上的發光泡泡是道具，撿到後右上角會顯示剩餘時間（最後兩秒會閃爍並嗶嗶提醒）：

| 道具 | 效果 |
| --- | --- |
| 衝刺鞋 | 速度 ×1.65，撞開柵欄；撞到列車會直接翻上車頂 |
| 噴射背包 | 飛到高空，沿路有一整排會換道的金幣；降落後有短暫無敵 |
| 金幣磁鐵 | 把附近三條軌道的金幣吸過來 |
| 雙倍金幣 | 每枚金幣算兩枚 |
| 彈跳鞋 | 跳得超高，可以直接跳上車頂 |
| 防護罩 | 抵擋一次撞擊 |
| 神秘寶箱 | 隨機得到金幣、+1000 分，或其他道具 |

## 關卡與服裝

- 十個場景各是一關。選該場景、一次跑完目標距離並收集足夠金幣就破關（例如第 1 關：700 m ＋ 50 金幣，越後面越難）
- 每破一關解鎖一套服裝，分數倍率 +1：列車長、衝浪少年、隧道工程師、雪地探險家、賽博浪人、西部牛仔、櫻花忍者、叢林探險家、熔岩消防員、太空人
- 十關全破解鎖「黃金傳奇」金色服裝
- 開始畫面的「關卡」可以看每關目標、「服裝」可以換裝（主畫面的角色會直接換上）

## 商店與續跑

- 每局的金幣會存進「金幣存款」，可以在「商店」升級道具的持續時間（每種 5 級）
- 撞車後可以花存款續跑（150 金幣，第二次 300），附近的障礙會被清掉並有短暫無敵；每局最多兩次
- 分數 =（距離 + 金幣 × 10 + 寶箱加分）× 分數倍率

## 音效

全部用 Web Audio 即時合成，不需要音檔：

- 每個場景有自己的配樂（節奏、和弦、音色都不同）和環境音：城市的鳥叫、海浪與海鷗、隧道低鳴與滴水聲、雪地風聲與風鈴、夜城的霓虹嗡嗡聲、沙漠風聲與老鷹、古都鐘聲、雨林蟲鳴、火山轟隆與熔岩冒泡、太空基地的通訊嗶聲
- 腳步聲會依地面改變：碎石、雪地、沙地、草地、濕地面、踩在車頂或斜坡上的金屬聲
- 跑越快風聲越大；迎面列車會有轟隆聲、車輪喀噠聲和喇叭
- 跳躍、滑鏟、落地、換道、擦身而過、吃金幣（連續吃音高會上升）、每 500 公尺提示音、開跑鈴聲、結束與破紀錄音效
- 右上角可以分別關閉音樂或全部靜音（快捷鍵 M）

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 換軌道 | ← → / A D | 左右滑 |
| 跳躍 | ↑ / W / 空白鍵 | 上滑 |
| 滑鏟（空中按下可快速落地） | ↓ / S | 下滑 |
| 暫停 | P / Esc | 右上角按鈕 |
| 靜音 | M | 右上角按鈕 |

## 執行

因為使用 ES Modules，需要透過本機伺服器開啟（直接雙擊 `index.html` 會被瀏覽器擋下）：

```bash
npx http-server . -p 8080
# 或
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。Three.js 由 jsDelivr CDN 載入，所以第一次需要網路。

也可以直接用 GitHub Pages 發佈這個資料夾。

## 畫面技術

- ACES 色調映射、PCF 軟陰影、HDR Bloom 後製、MSAA 抗鋸齒
- RoomEnvironment 環境反射（金幣和車身的金屬光澤）
- 自訂天空 Shader：漸層、太陽光暈、fbm 程序化雲層
- 所有貼圖（碎石、枕木、塗鴉牆、列車塗裝、大樓立面、海報）都用 Canvas 即時繪製，沒有任何圖片檔
- 音效與背景音樂用 Web Audio 即時合成
- 手機自動降低解析度與陰影品質

## 程式結構

```
index.html        介面（HUD、開始畫面、暫停、結算車票）
style.css
src/
  main.js         遊戲狀態、輸入、物理與碰撞、鏡頭、場景切換
  config.js       遊戲常數（速度、重力、車道位置…）
  themes.js       十個場景的天空、霧、光線、地面、粒子設定
  stage.js        渲染器、天空、燈光、Bloom、粒子、速度線、天氣粒子、場景過渡
  environment.js  無限循環場景：軌道 + 前五個場景的佈景
  scenes-extra.js 後五個場景（沙漠、櫻花、雨林、火山、太空）的佈景
  geo.js          幾何合併等共用工具
  level.js        關卡片段生成：列車、斜坡、柵欄、金幣、道具
  powerups.js     道具的 3D 模型
  progress.js     道具／關卡／服裝定義與存檔
  models.js       列車 / 斜坡 / 柵欄 / 金幣 3D 模型
  player.js       跑者角色、程序化動畫、12 套服裝與道具外觀
  textures.js     Canvas 程序化貼圖
  audio.js        Web Audio 音效、環境音、配樂
```

想再新增場景：在 `themes.js` 加一組設定、在 `scenes-extra.js` 加一個 `build_<id>()` 並登記到 `EXTRA_BUILDERS`，把 id 加進 `THEME_ORDER` 和 `index.html` 的場景按鈕，再到 `audio.js` 的 `MUSIC` 和 `buildBed()` 加配樂與環境音。障礙物配置在 `level.js` 的 `chunk_*` 函式。
