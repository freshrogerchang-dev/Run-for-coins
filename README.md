# 金幣酷跑 Run for Coins

3D 火車軌道跑酷遊戲，使用 [Three.js](https://threejs.org/) 製作。純靜態網頁，不需要建置步驟。

## 玩法

- 沿著三條軌道一直往前跑，吃金幣、閃避障礙
- **紅白柵欄**：跳過去
- **黃黑高架柵欄**：滑鏟從下面鑽過
- **停靠的列車**：換軌道閃開，或從**黃黑斜坡**跑上車頂
- **亮著頭燈的列車**會迎面開過來，要提早換道
- 換道時撞到側面會被彈回，3 秒內再撞一次就出局
- 速度會隨距離越來越快；分數 = 距離 + 金幣 × 10

## 場景

開始畫面可以選擇場景：

| 場景 | 特色 |
| --- | --- |
| 城市鐵道 | 塗鴉水泥牆、電車線、兩側大樓，偶爾經過「金幣大道站」月台 |
| 海岸線 | 右邊是沙灘和大海（帆船、燈塔、陽傘），左邊山坡上有彩色小屋和椰子樹 |
| 地鐵隧道 | 混凝土圓拱隧道、壁燈、天花板燈條、緊急出口燈；聲音有隧道回音 |
| 雪山列車 | 下雪、雪山、松樹、木柵欄、小木屋和雪人；腳步是踩雪聲 |
| 霓虹夜城 | 星空、發光大樓、霓虹招牌、彩色燈串、濕亮的地面 |
| 環遊模式 | 每 800 公尺換一個場景，燈光和天空會平滑過渡，進隧道前會看到山壁隧道口 |

## 音效

全部用 Web Audio 即時合成，不需要音檔：

- 每個場景有自己的配樂（節奏、和弦、音色都不同）和環境音：城市的鳥叫、海浪與海鷗、隧道低鳴與滴水聲、雪地風聲與風鈴、夜城的霓虹嗡嗡聲與遠方喇叭
- 腳步聲會依地面改變：碎石、雪地、濕地面、踩在車頂或斜坡上的金屬聲
- 跑越快風聲越大；迎面列車會有轟隆聲、車輪喀噠聲和喇叭
- 跳躍、滑鏟、落地、換道、擦身而過、吃金幣（連續吃音高會上升）、每 500 公尺提示音、開跑鈴聲、結束與破紀錄音效
- 右上角可以分別關閉音樂或全部靜音（快捷鍵 M）

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 換軌道 | ← → / A D | 左右滑 |
| 跳躍 | ↑ / W / 空白鍵 | 上滑 |
| 滑鏟（空中按下可快速落地） | ↓ / S | 下滑 |
| 暫停 | P / Esc | 右上角按鈕 |
| 靜音 | M | 右上角按鈕 |

## 執行

因為使用 ES Modules，需要透過本機伺服器開啟（直接雙擊 `index.html` 會被瀏覽器擋下）：

```bash
npx http-server . -p 8080
# 或
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。Three.js 由 jsDelivr CDN 載入，所以第一次需要網路。

也可以直接用 GitHub Pages 發佈這個資料夾。

## 畫面技術

- ACES 色調映射、PCF 軟陰影、HDR Bloom 後製、MSAA 抗鋸齒
- RoomEnvironment 環境反射（金幣和車身的金屬光澤）
- 自訂天空 Shader：漸層、太陽光暈、fbm 程序化雲層
- 所有貼圖（碎石、枕木、塗鴉牆、列車塗裝、大樓立面、海報）都用 Canvas 即時繪製，沒有任何圖片檔
- 音效與背景音樂用 Web Audio 即時合成
- 手機自動降低解析度與陰影品質

## 程式結構

```
index.html        介面（HUD、開始畫面、暫停、結算車票）
style.css
src/
  main.js         遊戲狀態、輸入、物理與碰撞、鏡頭、場景切換
  config.js       遊戲常數（速度、重力、車道位置…）
  themes.js       五個場景的天空、霧、光線、地面、音效設定
  stage.js        渲染器、天空、燈光、Bloom、粒子、速度線、下雪、場景過渡
  environment.js  無限循環場景：軌道 + 各場景的佈景
  level.js        關卡片段生成：列車、斜坡、柵欄、金幣
  models.js       列車 / 斜坡 / 柵欄 / 金幣 3D 模型
  player.js       跑者角色與程序化動畫
  textures.js     Canvas 程序化貼圖
  audio.js        Web Audio 音效、環境音、配樂
```

想再新增場景：在 `themes.js` 加一組設定、在 `environment.js` 加一個 `build_<id>()`，再到 `audio.js` 的 `MUSIC` 和 `buildBed()` 加配樂與環境音。障礙物配置在 `level.js` 的 `chunk_*` 函式。
