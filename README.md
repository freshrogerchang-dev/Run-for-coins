# 金幣酷跑 Run for Coins

3D 火車軌道跑酷遊戲，使用 [Three.js](https://threejs.org/) 製作。純靜態網頁，不需要建置步驟。

## 玩法

- 沿著三條軌道一直往前跑，吃金幣、閃避障礙
- **紅白柵欄**：跳過去
- **黃黑高架柵欄**：滑鏟從下面鑽過
- **停靠的列車**：換軌道閃開，或從**黃黑斜坡**跑上車頂
- **亮著頭燈的列車**會迎面開過來，要提早換道；車子接近前，那條車道的地上會閃紅色箭頭、畫面上方出現驚嘆號，還有兩聲嗶嗶提醒
- 換道時撞到側面會被彈回，3 秒內再撞一次就出局
- 速度會隨距離越來越快；分數 = 距離 + 金幣 × 10

## 道具

跑道上的發光泡泡是道具，撿到後右上角會顯示剩餘時間（最後兩秒會閃爍並嗶嗶提醒）：

| 道具 | 效果 |
| --- | --- |
| 衝刺鞋 | 速度 ×1.65，撞開柵欄；撞到列車會直接翻上車頂 |
| 噴射背包 | 飛到高空，沿路有一整排會換道的金幣；降落後有短暫無敵 |
| 金幣磁鐵 | 把附近三條軌道的金幣吸過來 |
| 雙倍金幣 | 每枚金幣算兩枚 |
| 彈跳鞋 | 跳得超高，可以直接跳上車頂 |
| 防護罩 | 抵擋一次撞擊 |
| 神秘寶箱 | 隨機得到金幣、+1000 分，或其他道具 |
| 時光沙漏 | 整個世界慢下來（速度 ×0.62），更容易閃避 |
| 金幣雨 | 前方三條路同時從天上掉下 90 公尺長的金幣 |
| 巨人蘑菇 | 變成巨人，連列車、動物、斜坡都能直接撞飛 |

另外還有：

- **加速帶**：路上的藍色發光箭頭，踩到會衝刺 1.6 秒，後面通常接一排金幣
- **金幣連擊**：0.6 秒內連續吃金幣會累積連擊，每 10 連擊送分數（連擊數 × 5）
- **寵物**：在「角色・寵物」購買，會跟在身旁飛，各有能力——小狗旺財（開局 12 秒防護罩）、小貓咪咪（磁鐵與雙倍金幣多 3 秒）、小龍噴噴（開局衝刺 3 秒）、貓頭鷹博士（每 50 枚金幣多送 5 枚）

## 新手教學與手感

- **新手教學**：第一次玩會先跑一段教學跑道，遇到障礙時畫面變慢並顯示手勢提示，照著做（換道、跳、滑鏟）才會繼續；教學中撞到不會輸。開始畫面的「重看新手教學」可以再跑一次
- **前 400 公尺保護**：一開始不會出現迎面車輛和三條道全擋的組合
- **打擊感**：撞擊瞬間停格、畫面閃色、手機震動（Android）；落地會壓扁、起跳會拉長，換道時角色和鏡頭會傾斜
- **衝刺光暈**：衝刺鞋、加速帶、火箭板衝刺時，角色全身發出金色光暈，手腳拖出光帶，身邊有光線掠過，速度線也變成金色
- **加分飄字**：和迎面來車擦身而過 +50、越過柵欄 +25（乘上分數倍率）
- **結算畫面**：告訴你怎麼輸的和避開的方法，並列出離最高分、破關、活動、每日字母、下一個能解鎖的東西還差多少

## 每日登入、每日字母、季節活動

- **每日登入**：連續七天有獎勵（金幣、滑板），第七天 1000 金幣 + 2 塊滑板；中斷一天從第一天重新開始
- **每日字母**：每天一個英文單字（例如 SPEED、PANDA），跑道上偶爾出現紫色字母，照順序收集拼完送 400 金幣 + 1 塊滑板
- **季節活動**：依日期自動切換，跑道上會出現活動代幣，收集 30／80／150／250 個分別換金幣、滑板、限定服裝、大量金幣

## 關卡與服裝

- 十八個場景各是一關。選該場景、一次跑完目標距離並收集足夠金幣就破關（例如第 1 關：700 m ＋ 50 金幣，越後面越難）
- 每破一關解鎖一套服裝，分數倍率 +1：列車長、衝浪少年、隧道工程師、雪地探險家、賽博浪人、西部牛仔、櫻花忍者、叢林探險家、熔岩消防員、太空人、潛水員、甜點師、恐龍裝、小巫師、飛行員、熊貓裝、日本站務員、輕軌司機
- 十八關全破解鎖「黃金傳奇」金色服裝
- 開始畫面的「關卡」可以看每關目標、「服裝」可以換裝（主畫面的角色會直接換上）

## 重新開始與重置

- **暫停選單**：可以「重新開始這一局」或「回到月台」，這局撿到的金幣會存進存款
- **重置遊戲進度**：開始畫面最下面的「重置遊戲進度」，確認後會清除所有進度（分數、金幣、關卡、服裝、角色、寵物、任務、成就、活動），畫質與音效設定會保留

## 商店與續跑

- 每局的金幣會存進「金幣存款」，可以在「商店」升級道具的持續時間（每種 5 級）
- 撞車後可以花存款續跑（150 金幣，第二次 300），附近的障礙會被清掉並有短暫無敵；每局最多兩次
- 分數 =（距離 + 金幣 × 10 + 寶箱加分）× 分數倍率

## 每日任務、成就、角色

- **每日任務**：每天三個新任務（例如「跳躍 35 次」「在車頂上跑 250 公尺」「甩掉站務員 2 次」），午夜更新。完成一個拿金幣，三個全部完成再加 500 金幣和一塊滑板
- **成就**：20 個成就（跳跳虎、馬拉松、破壞王、風雨無阻、全關制霸…），各有進度條和金幣獎勵
- **角色**：用金幣存款解鎖，服裝可以穿在任何角色身上，每個角色有自己的能力——阿橘（衝刺鞋和加速帶多 1 秒）、小美（磁鐵多 3 秒）、機器人波特（續跑費用減半）、狐狸阿福（跳得更高）

## 追趕者、滑板、天氣

- **站務員和狗**：開局會追一小段；換道撞到側面時他會追上來，3 秒內再撞一次就會被抓
- **滑板**：按 **B** 或點兩下畫面使用，30 秒內擋一次撞擊。每人先送 2 塊，商店 200 金幣一塊，每日任務全完成也送
- **滑板種類**（商店購買後選用）：經典滑板、彈跳板（跳更高）、火箭板（先衝刺 3 秒）、磁力板（自動吸金幣）、二段跳板（空中可再跳一次）
- **暴風雨**：戶外場景會隨機下暴風雨，天色變暗、下雨、閃電打雷；隧道、太空、雪山、火山不會下雨

## 音效

全部用 Web Audio 即時合成，不需要音檔：

- 每個場景有自己的配樂（節奏、和弦、音色都不同）和環境音：城市的鳥叫、海浪與海鷗、隧道低鳴與滴水聲、雪地風聲與風鈴、夜城的霓虹嗡嗡聲、沙漠風聲與老鷹、古都鐘聲、雨林蟲鳴、火山轟隆與熔岩冒泡、太空基地的通訊嗶聲
- 腳步聲會依地面改變：碎石、雪地、沙地、草地、濕地面、踩在車頂或斜坡上的金屬聲
- 跑越快風聲越大；迎面列車會有轟隆聲、車輪喀噠聲和喇叭
- 跳躍、滑鏟、落地、換道、擦身而過、吃金幣（連續吃音高會上升）、每 500 公尺提示音、開跑鈴聲、結束與破紀錄音效
- 右上角可以分別關閉音樂或全部靜音（快捷鍵 M）

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 換軌道 | ← → / A D | 左右滑 |
| 跳躍 | ↑ / W / 空白鍵 | 上滑 |
| 滑鏟（空中按下可快速落地） | ↓ / S | 下滑 |
| 用滑板 | B | 點兩下畫面，或右上角「滑板」按鈕 |
| 暫停 | P / Esc | 右上角按鈕 |
| 靜音 | M | 右上角按鈕 |

## 執行

因為使用 ES Modules，需要透過本機伺服器開啟（直接雙擊 `index.html` 會被瀏覽器擋下）：

```bash
npx http-server . -p 8080
# 或
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。Three.js 由 jsDelivr CDN 載入，所以第一次需要網路。

## 發佈到網路上

這是純靜態網站，不用建置，任何靜態主機都可以放。

### GitHub Pages（最簡單）

1. 打開 GitHub 上的 repo → **Settings** → 左側 **Pages**
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選 `claude/parkour-game-prototype-1epnsp`，資料夾選 `/ (root)`，按 **Save**
4. 等一兩分鐘，網址會是 <https://freshrogerchang-dev.github.io/Run-for-coins/>

之後每次推送到這個分支，網站會自動更新。repo 裡的 `.nojekyll` 讓 GitHub 直接提供檔案，不經過 Jekyll 處理。

### Cloudflare Pages

1. Cloudflare 後台 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 選這個 repo 和分支 `claude/parkour-game-prototype-1epnsp`
3. **Framework preset** 選 None，**Build command** 留空，**Build output directory** 填 `/`
4. 部署完成後會得到 `https://<專案名稱>.pages.dev` 網址

## 畫面技術

- ACES 色調映射、PCF 軟陰影、HDR Bloom 後製、MSAA 抗鋸齒
- RoomEnvironment 環境反射（金幣和車身的金屬光澤）
- 自訂天空 Shader：漸層、太陽光暈、fbm 程序化雲層
- 所有貼圖（碎石、枕木、塗鴉牆、列車塗裝、大樓立面、海報）都用 Canvas 即時繪製，沒有任何圖片檔
- 音效與背景音樂用 Web Audio 即時合成
- 手機自動降低解析度與陰影品質
